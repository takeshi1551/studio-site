# Сайт-приложение студии (версия 1)

Это готовая страница студии в формате PWA. Язык сайта: украинский, цены в гривнах (₴). Её можно открыть по ссылке, а на телефоне добавить на главный экран, и она будет открываться как обычное приложение, со своей иконкой и без адресной строки. Сохранённая копия открывается и без интернета.

В версии 1 нет онлайн-записи: кнопка «Записаться» предлагает позвонить или написать в Telegram. Запись, кабинет владельца и ИИ-помощник будут в следующих версиях.

Всё бесплатно: GitHub и Vercel (тариф Hobby). Важно: по правилам Vercel тариф Hobby разрешён только для личных некоммерческих проектов. Для теста этого достаточно. Когда будете показывать сайт реальным студиям как коммерческое предложение, нужен платный тариф Vercel Pro.

## Эффекты на странице

- **Главный экран:** при открытии по кузову проходит блик, название появляется по словам, затем текст и кнопка. Фото чуть медленнее прокручивается, чем страница (параллакс), а кнопка «Записатися» едет вместе с ним.
- **Стеклянная кнопка:** блик под пальцем или курсором следует за ним.
- **Слайдер «до / після»:** тянется пальцем, мышью и стрелками клавиатуры. В начале один раз сам покачивается, показывая, что его можно двигать. Если не нужен, удалите блок `compare` в `config.js`.
- **Нижняя панель:** стеклянная, подсвечивает текущий раздел.
- Если у человека в телефоне включено «уменьшить движение», все эти анимации отключаются, страница остаётся полностью рабочей.

Все эффекты написаны без сторонних библиотек, поэтому работают и без интернета.

## Что внутри

| Файл | Зачем |
|---|---|
| `config.js` | Все данные студии (на украинском): название, цены, адрес, телефон, график. **Главный файл для правок** |
| `manifest.webmanifest` | Название и иконка под приложением на телефоне |
| `images/` | Фотографии: `hero.jpg` (главное), `work-1..4.jpg` (работы), `before.jpg` и `after.jpg` (слайдер «до / после») |
| `icons/` | Иконки приложения |
| `index.html`, `styles.css`, `app.js` | Страница и оформление. Обычно их трогать не нужно |
| `sw.js` | Работа без интернета |

## Шаг 1. Посмотреть на компьютере (по желанию)

Откройте папку в терминале и выполните `python3 -m http.server 8000`, затем откройте в браузере `http://localhost:8000`. Просто двойной клик по `index.html` тоже покажет страницу, но установка и офлайн-режим при этом не заработают, они требуют адреса `http://localhost` или `https://`.

## Шаг 2. Загрузить на GitHub

1. Зарегистрируйтесь на github.com (нужна только почта).
2. Нажмите **New repository**, назовите, например, `studio-site`, выберите **Public**, нажмите **Create repository**.
3. На странице нового репозитория нажмите **uploading an existing file**.
4. Перетащите **содержимое** папки (файлы и папки `icons`, `images`, а не саму папку-обёртку). Нажмите **Commit changes**.

## Шаг 3. Опубликовать на Vercel

1. Зарегистрируйтесь на vercel.com через кнопку **Continue with GitHub**.
2. Нажмите **Add New → Project**, выберите свой репозиторий, нажмите **Import**.
3. Ничего не меняйте в настройках (**Framework Preset: Other**, команды сборки не нужны) и нажмите **Deploy**.
4. Через минуту появится ссылка вида `название.vercel.app`. Это и есть ваш сайт.

Каждый раз, когда вы меняете файлы на GitHub, Vercel сам обновляет сайт.

## Шаг 4. Поменять данные на свои

1. На GitHub откройте файл `config.js`, нажмите значок карандаша.
2. Замените текст в кавычках: название, цены, телефон, ссылку на Telegram, адрес, график.
3. Цены в `config.js` указаны в гривнах, пересчитаны из рублей примерно по курсу 1 ₴ ≈ 1,8 ₽ (курс на август 2026), поставьте свои. Поставьте `demo: false`, когда данные станут настоящими (уберёт надпись «Это пример»).
4. Название под иконкой на телефоне меняется в `manifest.webmanifest` (`name` и `short_name`).
5. Нажмите **Commit changes** и подождите минуту.

### Фотографии

Сейчас в `images/` лежат **временные тёмные заглушки**, а не фото машин: я не смог скачать снимки из интернета (в моей среде нет доступа к сети). Заменить их просто:

1. Скачайте снимки с сайтов, где фото можно использовать бесплатно, например Unsplash (unsplash.com) или Pexels (pexels.com). Ищите «car detailing», «car polishing», «black sedan», «car interior». Перед использованием прочитайте лицензию на странице снимка. Фото из случайной выдачи поиска брать нельзя, у них есть авторы и права.
2. Переименуйте файлы: главное фото в `hero.jpg`, фото работ в `work-1.jpg` … `work-4.jpg`.
3. На GitHub откройте папку `images`, нажмите **Add file → Upload files**, загрузите файлы **с теми же именами** и нажмите **Commit changes**.

Для слайдера «до / после» нужны два снимка **одной и той же машины с одного ракурса**: до полировки и после. Иначе сравнение не будет работать. Хорошо подходят снимки до 1–2 МБ. Главное фото лучше горизонтальное, фото работ квадратные или близкие к квадрату.

Ссылками на картинки с чужих сайтов пользоваться не стоит: они могут пропасть, и в режиме без интернета их не будет.

**После замены данных или фото** откройте `sw.js` и увеличьте число в строке `const VERSION = "2";` (например, на `"3"`). Иначе у тех, кто уже открывал сайт, какое-то время будет показываться старая сохранённая копия.

## Шаг 5. Проверить на телефоне

- **Android (Chrome):** откройте ссылку, внизу страницы нажмите «Установить приложение» (или меню браузера → «Установить приложение»).
- **iPhone (Safari):** откройте ссылку в Safari, нажмите «Поделиться» → «На экран Домой» → «Добавить». Кнопка «Установить приложение» на странице покажет эти шаги.
- Включите авиарежим и откройте иконку: страница должна открыться.

## Что проверено, а что нет

Проверено в автоматическом браузере (включая эффекты, слайдер мышью и клавиатурой, режим «уменьшить движение») на экране размера телефона: страница открывается, данные подставляются из `config.js`, кнопка «Записаться» открывает окно, нижняя навигация переключается, сайт открывается без сети после первого визита.

Не проверено: установка на реальном iPhone и Android, внешний вид на конкретных телефонах, публикация на вашем Vercel. Проверьте это на своих устройствах.
